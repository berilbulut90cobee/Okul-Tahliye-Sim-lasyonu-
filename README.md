# Okul Tahliye Simülasyonu

Genç Girişimciler yarışması için geliştirdiğimiz, okulumuzun iki binasında (Eyüboğlu Koleji ve Fen Lisesi) acil durum tahliyesini 3 boyutlu gösteren simülasyon.

## Senaryolar
- Deprem: Önce çök-kapan-tutun, sonra en yakın çıkışa tahliye
- Yangın: Seçilen yerdeki yangın ve duman o yolu kapatır, öğrenciler başka yol bulur
- Saldırı (kilitlenme): Kapılar kilitlenir, öğrenciler kapıdan görünmeyen köşede toplanır
- Su baskını: Alt katlardakiler 2. kata çıkar
- Gaz kaçağı: Hızlı tahliye

## Ölçtükleri
Tahliye süresi, merdiven ve kapılardaki kuyruklar, kullanılan çıkışlar, binalar arası geçişleri kullananlar ve mahsur kalanlar.

## Nasıl açılır?
index.html dosyasını tarayıcıda açın (internet bağlantısı gerekir) ya da GitHub Pages bağlantısını kullanın.

## Teknoloji
HTML, CSS, JavaScript, three.js (3D), Dijkstra en kısa yol algoritması ve kapasite sınırlı kuyruk modeli.
